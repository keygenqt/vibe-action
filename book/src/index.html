# Quick Start

## 1. Install Ollama (or DeepSeek)

## 2. Install Vibe Action
cargo install vibe-action

## 3. AI-powered commit
vibe-action commit -p .

## 4. Translate files
vibe-action translate -f README.md -l Russian

## 5. Extract errors from logs
vibe-action extract -f app.log -q 'find errors'
